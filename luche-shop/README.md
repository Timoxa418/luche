# Luche — Telegram-магазин детской одежды

Мини-приложение для Telegram: каталог, карточки товаров с размерами, корзина и онлайн-оплата.
Карточки переносятся из вашего кабинета Wildberries одной командой.

## Что внутри

| Файл | Зачем |
|---|---|
| `public/index.html` | Сам магазин (то, что видит покупатель) |
| `public/products.json` | Каталог. Создаётся импортом, руками править не нужно |
| `import-wb.mjs` | Перенос карточек с WB |
| `overrides.json` | Ваши ручные правки поверх WB (скрыть товар, сменить цену и т. д.) |
| `server.mjs` | Сервер: отдаёт магазин, создаёт счёт на оплату, принимает оплату, пишет вам в Telegram |
| `.env` | Ваши настройки и токены (создаётся из `.env.example`) |

Нужен только Node.js 18 или новее. Устанавливать пакеты не требуется.

## Шаг 1. Посмотреть, как это выглядит (без токенов)

```
node server.mjs
```

Откройте http://localhost:3000. В каталоге будут 5 тестовых товаров. Корзина работает, оплата в этом режиме
только проверяет заказ (оплатить можно лишь внутри Telegram).

## Шаг 2. Перенести карточки с Wildberries

1. Кабинет WB → Профиль → Настройки → **Доступ к API** → создать токен.
   Нужны права на чтение разделов **«Контент»** и **«Цены и скидки»**.
2. В Railway → Variables задайте:
   - `WB_TOKEN` — токен с правами чтения «Контент» и «Цены и скидки».
   - `WB_MARKETPLACE_TOKEN` — отдельный токен с правами чтения складов и остатков в разделе «Маркетплейс».
   - `WB_WAREHOUSE_ID` — необязательно; если задан, синхронизируется только этот склад. Если не задан, скрипт получает список складов продавца и суммирует остатки по ним.
3. Импорт запускается командой `npm run import`.
4. Для локального запуска выполните:

```
node import-wb.mjs
```

Скрипт скачает все ваши карточки (название, описание, размеры, характеристики, цену) и до 5 фото на товар
в папку `public/img`. Результат — `public/products.json`.
Когда добавите или измените товары на WB, просто запустите команду ещё раз.

Важно:
- Переносятся **ваши собственные** карточки (по токену вашего кабинета).
- Цена берётся из `discountedPrice` — цена продавца после его скидки. Покупатель на WB может видеть другую сумму из-за дополнительных скидок WB, СПП и WB Клуба. Универсальную персональную цену покупателя API продавца не гарантирует.
- Остатки FBS берутся по `chrtID` каждого размера и суммируются по складам продавца. Размер без остатка показывается как недоступный.
- Сервер повторно синхронизирует цены и остатки каждые 5 минут. Интервал можно изменить переменной `WB_SYNC_INTERVAL_MS` (миллисекунды, минимум 60000).
- При ошибке чтения цен или остатков импорт завершается с ошибкой и не заменяет последний успешный каталог.

### Ручные правки: `overrides.json`

Ключ — номер артикула WB (nmID). Они сохраняются при каждом новом импорте.

```json
{
  "100000001": { "price": 1290, "oldPrice": 1590 },
  "100000002": { "hidden": true },
  "100000003": { "soldOutSizes": ["74", "80"], "category": "Верхняя одежда" },
  "100000004": { "title": "Футболка «Лучик»" }
}
```

Поля: `price`, `oldPrice`, `title`, `category`, `description`, `hidden` (скрыть товар), `soldOutSizes` (размеры, которых нет). Ручной `soldOutSizes` может скрыть размер, даже если WB сообщает остаток.

## Шаг 3. Бот и оплата в Telegram

1. В **@BotFather** создайте бота командой `/newbot` и скопируйте токен в `BOT_TOKEN`.
2. Там же: ваш бот → **Payments** → выберите платёжного провайдера (например, ЮKassa), подключите магазин
   по инструкции провайдера. BotFather выдаст платёжный токен — вставьте в `PROVIDER_TOKEN`.
   Сначала используйте **тестовый** токен провайдера и проверьте оплату тестовой картой.
3. Узнайте свой chat id у бота **@userinfobot** и впишите в `MANAGER_CHAT_ID`. Сюда будут приходить
   оплаченные заказы с адресом и телефоном покупателя. Напишите своему боту `/start`, чтобы он мог вам писать.
4. Если провайдер требует чек (ЮKassa): `RECEIPT=1`, укажите `TAX_SYSTEM_CODE` и `VAT_CODE`
   (подсказки в `.env.example`). Проверьте значения у своего бухгалтера или в документации провайдера.
5. Доставка: `SHIPPING_COST` и `FREE_SHIPPING_FROM` в `.env`.

## Шаг 4. Выложить на сервер

Telegram открывает мини-приложения только по **https**, поэтому магазин нужно разместить на сервере с доменом
и сертификатом. Подойдёт любой VPS или хостинг, где можно запустить Node.js (Render, Railway, Timeweb, Selectel и т. д.).

1. Загрузите папку проекта (вместе с `.env`) и запустите `node server.mjs`.
   Процесс должен работать постоянно (например, через pm2 или systemd), потому что бот принимает оплату
   через этот же процесс.
2. Впишите адрес в `WEBAPP_URL`, например `https://luche.example.com`, и перезапустите.
3. После запуска у бота появится кнопка меню «Магазин», а команда `/start` покажет кнопку «Открыть магазин».

## Как проходит заказ

1. Покупатель собирает корзину → «Оплатить».
2. Сервер сам пересчитывает суммы по каталогу (подменить цену в приложении нельзя) и создаёт счёт.
3. В окне оплаты Telegram покупатель вводит имя, телефон, адрес и платит.
4. Вам в Telegram приходит сообщение с составом заказа и данными покупателя, а заказ записывается в `data/orders.json`.

## Если что-то не работает

- «Откройте магазин из Telegram» — страницу открыли в обычном браузере, а не через бота.
- «Не задан PROVIDER_TOKEN» — не подключена оплата в BotFather (шаг 3).
- Нет уведомлений о заказах — проверьте `MANAGER_CHAT_ID` и что вы нажали `/start` у своего бота.
- Импорт пишет «WB отклонил токен» — у токена нет нужных прав или он истёк.
